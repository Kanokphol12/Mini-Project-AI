# Mini Project AI - Thai Sentiment Analysis Web App

แอปพลิเคชันสำหรับวิเคราะห์อารมณ์ของข้อความภาษาไทย โดยใช้ Streamlit และ AIForThai API

## ฟีเจอร์หลัก
- รองรับการกรอกข้อความภาษาไทยผ่าน UI (Streamlit)
- เชื่อมต่อกับ AIForThai SSense API ผ่าน HTTP POST Request
- แสดงผลการวิเคราะห์อารมณ์ (Positive / Negative / Neutral)
